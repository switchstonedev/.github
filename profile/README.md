# SwitchStone

Independent software workshop building developer tooling, reproducible benchmarks, and algorithmic engines.

## Active Projects

- **Vector DB Benchmark Suite** (In Development) — Reproducible throughput, recall@k, and tail-latency benchmarking across vector search engines.
- **CP Recommendation Engine** (In Development) — Personalized algorithmic problem recommender tailored to rating progression and topic gaps.
