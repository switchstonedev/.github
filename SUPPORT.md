# Support

Welcome to the SwitchStone community. To ensure questions and issues are addressed efficiently, use the appropriate communication channels below.

## Routing Guidelines

- **Bug Reports & Feature Requests:** Open an issue in the relevant repository using the structured issue forms under `.github/ISSUE_TEMPLATE`. Please search existing open and closed issues before opening a new one.
- **Usage Questions & Architectural Ideas:** If the target repository has **GitHub Discussions** enabled, start a discussion thread there. If Discussions are not enabled, check existing issues and repository documentation.
- **Benchmark Reproductions & Technical Feedback:** For inquiries regarding benchmark methodologies or dataset configurations (such as the Vector DB Benchmark Suite), open an issue on the respective repository tagged with relevant context.
- **Security Vulnerabilities:** Follow the instructions in [SECURITY.md](SECURITY.md). Do not report security vulnerabilities in public issues or discussion threads.
