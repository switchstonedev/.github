# SwitchStone Organization Meta Repository (`.github`)

This repository serves as the organization-level fallback layer for [SwitchStone](https://github.com/switchstonedev).

Repositories created under `switchstonedev` automatically inherit these community health files, issue forms, pull request templates, and funding configurations unless an individual repository specifies its own local override.

## Structure

- `profile/` — Landing page content displayed on the [SwitchStone Organization Profile](https://github.com/switchstonedev).
- `.github/ISSUE_TEMPLATE/` — Organization-wide issue forms (`bug_report.yml`, `feature_request.yml`) and configuration (`config.yml`).
- `.github/PULL_REQUEST_TEMPLATE.md` — Default pull request template.
- `.github/FUNDING.yml` — Organization sponsorship configuration.
- `CODE_OF_CONDUCT.md` — Contributor Covenant v2.1 code of conduct.
- `CONTRIBUTING.md` — Contribution workflow, commit conventions, and testing requirements.
- `SECURITY.md` — Vulnerability reporting policy via GitHub Private Vulnerability Reporting.
- `SUPPORT.md` — Channel routing for bugs, questions, and benchmark inquiries.
